# 🇮🇳 Our Government AI Assistant

## **Overview**

Our Government AI Assistant is an AI-powered chatbot designed to provide information about the Government of India, ministries, cabinet members, government departments, and national initiatives.

The chatbot uses the **Qwen 0.6B Large Language Model**, integrated with a professional **Gradio UI**, and fetches official government information directly from the PM India website.

---

# 🚀 Features

* **AI-powered Government Assistant**
* **Interactive Chat Interface**
* **Professional Gradio UI**
* **Official Government Information**
* **Live Data Scraping from PM India**
* **Conversation Memory**
* **Fast AI Responses**
* **Google Colab Ready**

---

# 🛠 Tech Stack

* **Python**
* **Transformers**
* **Torch**
* **Gradio**
* **BeautifulSoup4**
* **Requests**
* **Qwen/Qwen3-0.6B**

---

# 📌 Project Workflow

1. Load the Qwen AI model
2. Fetch official government information
3. Create system prompt using scraped data
4. Generate AI responses
5. Display responses using Gradio Chat UI
